🥦 花椰菜家族 · 分形涌现

Romanesco / Cauliflower / Broccoli 三种形态 + 🪷直立花盘（蜂窝上复刻 Broccoli Equation 对数螺旋算法）+ 🎄圣诞树创意。核心锥面螺旋递归源自 Rodrigo Setti《The Broccoli Equation》IFS 四矩阵（见页末来源）。

形态预设（整合三种算法）

⚽ 正60面体＝截角二十面体（足球烯 C60 结构）：60 顶点 / 90 棱 / 32 面，其中 12 个正五边形 + 20 个正六边形。每个面像贴砖一样铺满直立花盘：
• 五边形面 → 5 株环绕、中心留空；
• 六边形面 → 6 株环绕 + 中心 1 株偏小（中实）；
• 每面淡灰色多边形底砖与相邻面共边，严丝合缝；切换此预设后自动关闭平面大六边形底盘与三角补株。
⬟ 正五边形花盘＝单块正五边形淡灰底砖平放，顶面按 5 个顶点方向贴直立花盘：5 株环绕彼此平放相切、不重叠；用下方开关决定是否补中心那株偏小的圆锥（勾＝6 株中实，不勾＝5 株中空）。花盘半径 / 环绕半径按真实几何精确相切计算。
IFS 用五重对称的收缩映射布株：p ← s·p + (1−s)·Vk，s = 1/(1+φ) = (3−√5)/2 ≈ 0.381966，Vk 为五个顶点（+ 中心/尖顶）。
• Sierpinski 五边形：每个副本以顶点为不动点收缩，相邻副本在该顶点相切；递归 2 层＝6²=36 株，1 层＝6 株。
• 五棱锥花盘山＝山（五棱锥坡面）+ 树（沿坡面法线的花盘）+ 铺满（面内覆盖求解）。
为什么不能靠混沌游戏铺满：混沌游戏只在"无限细分"的极限下铺满三角形，有限个点一定成团、团间一定留洞（加大 N 只把洞变小）。更根本的是单个花盘自身就漏：7 个底盘锥相切（环半径 2b）时，相邻花瓣在 30° 方向留 6 个凹口，最近只到 0.42 倍花盘半径 —— 任何摆法都补不上。
求解器（一键最优）：① 7 圆盘并集无孔 → 花瓣环收到 1.70b（重叠 15%，圆心三角形外接圆 0.98b<b）；② 三角格点间距 d = 1.44·rf（相切平铺 √3·rf 仍留 4~9% 齿槽）；③ 抖动 0.12d 去机械感；④ 覆盖率栅格 + BFS 距离场，在最大空洞补 0.4~0.9 倍小花盘（自相似尺度层级），迭代到栅格全覆盖。结果按 HUD 覆盖率 验收，不靠肉眼。

生长控制

分形几何参数

以上三项仅对三种分形塔（罗马花椰菜/花椰菜/西兰花）生效。第0级连片主体会渲染中央母锥，把原本散开的子锥连成一座山/树（levels=1 尤其明显）；落地底盘托住塔底。另：🚫 删除底面暴露锥（在直立花盘参数区）已全局生效——凡世界轴接近水平/朝下、底面会露出平底的锥，从数学底层连同子树一起删除，任何角度都看不到圆锥底面。

直立花盘 · 蜂窝参数

两级六边形蜂窝：整盘为六边形同心环（1+6+12+18…，留缝）；每一株自身的底盘也是 1 中心 + 6 环绕相切的六边形蜂窝（从底下看即“生命之花”）。7 个底盘锥底面平放平台，其上按所选底层分布算法递归建多级（级数见 levels）。
• 黄金角：菲波那契螺旋，密铺但非镜像对称；
• 白银比/六重/八重…：芽按“环”量化、同环等高、环间错半格 → 真正旋转对称。自相似层数 levels 已按严格层级修正：1 = 只有底盘 7 锥（无子代），2 = 再多完整一代子锥，3 = 再多两代，以此类推；预算会自动收敛每级芽数以保证子树完整、不露底盘。
• 自动填满空隙：圆密铺会在三株之间留下弧边三角孔洞（红点标注处），开启后自动识别每个“三株互邻”的三角中心并补一株缩小花球；补株大小可调（0.20～1.00×，默认 0.96×），锥数纳入统一预算、不会卡死。
• 淡灰色六边形砖底盘：一整块正六棱柱包络所有花球（6 条直边标准六边形），向上抬升、顶面插入株底形成部分重叠；厚度与重叠高度可调，并一并写入 STL/OBJ/PLY/STEP。

视觉

两种效果叠加：① 每株按黄金角叶序分成 N 条螺旋臂，相邻臂严格异色（黄/绿/紫交替）；② 按分形层级从深到浅着色（底层深、顶层浅）。

导出模型

满铺蜂窝请用「形态预设 → 直立花盘」，把蜂窝单元数 upN 调大并开启自动填满即可，无需单独的蜂窝面板。
支持 STL / OBJ / PLY / STEP，单位 mm，含底板 + 所有锥体（封闭实体）。STEP 面数 >3 万时会提示改用其它格式。

3D 打印 · 水密体重铸

上面导出的模型是「视觉实体」：每个锥各带一套封闭三角面、彼此穿插 → 切片软件会报非流形边/自相交。这里把所有锥写成有符号距离场做真布尔并集（min + 平滑并集），再用 Surface Nets 重铸成闭合网格：边界边 0（没有任何孔洞），三角面数比原始少一个数量级。代价：精度受体素限制；薄壁处可能残留极少量亚体素级自接触边（Surface Nets 的固有行为，切片软件会自动处理）。
输出文件名带 _watertight 后缀；体素粗时细小锥尖会被平滑掉，属正常现象（提高精度可保留细节）。

数学模型（源码级）

α = 137.507° = 360°/φ² (黄金角) sᵢ = i · h/N (沿锥轴下行) θᵢ = i · α (旋转) rᵢ = (R/L) · sᵢ (锥面半径) x=r cosθ, y=y₀+s, z=r sinθ Broccoli = Cone ∪ S2·R·T·Broccoli (IFS) S1: 整体缩至 1/2 a = 1/2 S2: 芽底大顶小 b = 1/100 R : 旋转芽朝外(远离锥心) T : 按锥面对数螺旋平移 r = a·e^(bθ) 对数螺旋(锥面展开) number of cones = (200π)ⁿ
源头：Rodrigo Setti — The Broccoli Equation（IFS 四矩阵 S1/S2/R/T，a=1/2、b=1/100，(200π)ⁿ 锥体）；参考 Robert Vella 的 Processing 实现（黄金角 2.399963、锥面螺旋取点）。本页增强：生长动画、蜂窝直立花盘、少锥近似、多格式导出。
